MovieHub – Cinematic Experience Platform

MovieHub is a high-performance, full-stack movie application designed for cinephiles to discover, track, and discuss their popular films. Built with a modern React architecture and a premium "streaming service" aesthetic, the platform bridges the gap between passive viewing and community engagement.

 The Problem & Solution

The Problem:
Movie lovers often struggle with fragmented experiences—switching between different apps to find recommendations, track their watchlists, and discuss films with a community. Existing platforms often lack a cohesive, responsive UI or robust organization tools.

The Solution:
MovieHub provides a centralized ecosystem where users can:

Explore global trending cinema with real-time filtering.

Manage a personalized "Cinematic Identity" via Watchlists and popular.

Engage with the community through a structured review system.

Experience a high-fidelity UI optimized for all devices.

Core Features

 Authentication & Identity


Profile Management: Personalized dashboards tracking viewing statistics and history.

 Discovery System

Global Catalog: Browse a curated list of trending movies and new releases.

Multiverse Search: Real-time search by title with instant UI updates.


 Personalization

The Queue (Watchlist): Add movies for future viewing with one click.

Interactive Modals: High-detail views featuring plot summaries, ratings, and community reviews.

 Admin Command Center

System Analytics: Visual engagement data using Recharts (Stream hours, Active users).


Content Management: Oversight of platform categories and trending metrics.

 Tech Stack

Frontend Library: React.js (Functional Components, Hooks)

Styling: CSS 

State Management: React Context/State Logic


 Getting Started

Prerequisites

Node.js (v16.0.0 or higher)

npm 

Installation

Clone the repository:

git clone https://github.com/your-username/moviehub.git


Navigate to the project folder:

cd moviehub


Install dependencies:

npm install


Start the development server:

npm run dev
